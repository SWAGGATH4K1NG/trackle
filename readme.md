# Trackle

Network and hardware monitor for Windows.
Built with Python, Tauri, React and TypeScript.

## Stack
- **Backend**: Python + psutil
- **Frontend**: Tauri + React + TypeScript + Tailwind
- **Data**: Network connections, traffic, hardware stats in real time

## Setup

### Backend
```bash
pip install -r backend/requirements.txt
```

### Frontend
```bash
cd Trackle
npm install
npm run tauri dev
```
